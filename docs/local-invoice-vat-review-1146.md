# مراجعة ضريبة الفواتير المحلية — 1146

الدخول من المحاسبة أو الفواتير بزر «مراجعة ضريبة الفواتير مع المرفقات»، أو من تفاصيل الفاتورة / المشروع. شاشة الإقفال تحتوي اختصارًا لمراجعة الفاتورة، ويعاد فتح كشف المراجعة غير المعتمد بعد حفظ التصحيح حتى لا يعتمد المستخدم أرقامًا قديمة.

الأداة يدوية: تعرض PDF أو صورة محفوظة في IndexedDB أو بيانات مرفق محلية، دون طلب OCR أو رفع ملفات إلى المحادثة أو خدمة قراءة خارجية. التصحيح يُحفظ بمسار النظام المعتاد، وبالتالي يخضع لإعدادات مزامنته الحالية. لا يُضاف أو يُحذف مرفق. الملفات المفقودة تبقى مفقودة وتظهر رسالة، ولا تُستنتج ضريبتها من الإجمالي.

مرفقات المشروع لا تُنسب تلقائيًا إلى فاتورة بالاسم أو المبلغ. يختار المستخدم الملف الصحيح، باستثناء روابط invoiceId الصريحة أو المرفق الموجود في سجل الفاتورة نفسه. يحفظ سجل المراجعة مفتاح المرفق المختار واسمه دون نسخ محتواه.

يحدد المستخدم هل المبلغ شامل الضريبة أو بدونها أو أن الفاتورة بلا ضريبة. ثم يكتب ضريبة المستند أو يختار الحساب بنسبة يدخلها. تظهر الصافي والضريبة والإجمالي قبل الحفظ. يلزم تأكيد مراجعة الأصل. اختيار استرجاع الضريبة مستقل، وتركه غير محدد لا يمنح خصمًا تلقائيًا؛ تغيير الاختيار إلى غير محدد يلغي العلم الصريح دون تغيير مبلغ الضريبة.

تُحفظ vatReview وvatReviewHistory على الفاتورة مع القيم السابقة والجديدة والفاعل والوقت والبناء وطريقة الحساب ومفتاح المرفق. تحافظ الكتابة على باقي خصائص الفاتورة، وتتحقق من عدم تغير السجل أثناء المراجعة. الفاتورة الملغاة أو المشروع/الفترة المقفلان للعرض فقط. فشل الحفظ لا يضيف سجل نجاح أو يستبدل البيانات الأصلية. بعد نجاح الحفظ يعاد حساب العرض والقيود عبر وظائف النظام القائمة.
