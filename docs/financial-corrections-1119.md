## ما لا يمكن استنتاجه تلقائيًا
| البند | السبب والخطوة اللازمة |
|---|---|
| تاريخ مصروفات الموقع القديمة | حقل تاريخ صريح بتعديل المشروع؛ عند غيابه يظهر تنبيه بأن الحساب السنوي أولي دون اختراع سنة. السجلات التشغيلية غير المؤرخة تُعلّم كذلك. |
| تكرار الدفعات الفعلي | التجاوز لا يثبت أن دفعتين متطابقتان. زر المراجعة لا يصفر اليدوي عشوائيًا. يلزم فحص مستندات القبض/نسخة البيانات. |
| أهلية خصم الضريبة القديمة | يلزم مستند ورقم فاتورة ورقم ضريبي وإقرار صريح بالأهلية؛ لا تُخصم كل ضريبة بمجرد وجود مبلغ. |
| القيود المقفلة أو المعكوسة القديمة | لا يعاد كتابة تاريخ مقفل تلقائيًا؛ تحتاج إعادة فتح معتمدة أو قيد تسوية. يظهر تنبيه بدل الإخفاء. |
| سياسة الاعتراف بالإيراد وصافي الربح المحاسبي | أبقي الأساس الإداري المعلن: عقود مشاريع سنة البدء والتكاليف المؤرخة. سُمي مؤشر اللوحة بفائض/عجز العقود بعد التكاليف، وأزيل ادعاء أن الملخص الإداري قائمة دخل معتمدة. لم تُفرض سياسة اعتراف بالإيراد حسب الإنجاز أو تحويل جميع التكاليف إلى صافي بعد الضريبة. |
| تأكيد أرصدة الإنتاج | يحتاج نسخة JSON والمستندات؛ GitHub لا يتيح قراءة تخزين المتصفح الخاص بالمستخدم. |
